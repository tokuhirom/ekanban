# 0026. gpui の名前は ADR にだけ残す

- 日付: 2026-09-06
- 状態: 有効
- 関連: [0017](0017-moving-the-ui-to-tauri.md)、[0025](0025-the-tauri-migration-landed.md)、#118

## 状況

[0017](0017-moving-the-ui-to-tauri.md) で UI を gpui-kit から Tauri へ移し、gpui のクレートは #108 で消え、移行の設計文書は [0025](0025-the-tauri-migration-landed.md) で消えた。それでも `gpui` という語はソースに 45 箇所残っていた。どれもコードではなく**コメント**で、形はこうだった。

> gpui 版の `platform_support` をそのまま移しています。**登録の戻り値を信じずに環境そのものを先に見ます**——X11 の実装は、使えない環境でも成功したように見えるためです。

> 同じ日のカードは ID の順。並びが揺れないようにするためで、gpui 版の `archived_groups` と同じ決め方。

**これらは根拠のふりをした行になっていた。** 挙げられている `platform_support` も `archived_groups` も、このリポジトリには無い。読み手はそれを開けないので、書いてある一致が本当かどうかも、いまも守れているかどうかも確かめられない。確かめられない根拠は、次に触る人を止めるだけで、何も守らない。

移行の最中は違った。両方のコードが手元にあり、「同じであること」が受け入れ条件そのものだったので、一致を指すのは検証できる主張だった。着地した時点で、その前提が消えた。

## 決定

**根拠として、このリポジトリに無いものを挙げない。** この規則を `docs/DESIGN.md`「根拠の書き方」に置き、ソースの 45 箇所を書き直した。

- 一致で説明していた行は、**理由そのもの**で書き直す。「保存の形は gpui 版のまま」は「この形で書かれたデータベースを読み続けるため」に、「gpui 版の `next_card_id` と同じ動き」は「このテストが書いているのが、いまの手触りそのもの」に
- 理由が既に隣に書けている行は、末尾の「（gpui 版と同じ）」を落とすだけにする
- **判断は 1 つも変えない。** 振る舞い、規則、テストの中身はそのまま。変えたのはコメントと Markdown だけ

**そのうえで、ADR は書き換えない。** 0017 と 0025 は gpui の名前を出したまま残る。`gpui` という語がこのリポジトリに残るのは `docs/adr/` の中だけになる。

## 理由

**根拠は、読み手が開けるものでなければ働かないため。** 上のとおり。コメントが果たす仕事は「なぜこうなっているか」を次の人に渡すことなので、渡した先が開けない参照は仕事をしていない。

**経緯の置き場所は既に決まっているため。** `docs/adr/README.md` が「ADR は書き換えない」と決め、[0025](0025-the-tauri-migration-landed.md) が「移行の経緯そのものは ADR に残る」と書いた。ソースのコメントに移行の話が散っている状態は、その分担から外れていただけとも言える。ADR に集めれば、`docs/DESIGN.md` から ADR へ辿る道が 1 本だけになる。

**「消えた実装を指さない」は gpui に限らないため。** 次に何かを置き換えたときも同じことが起きる。gpui の掃除としてだけ書くと、規則ではなく一度きりの作業になる。

## 採らなかった案

- **ADR も含めて `gpui` を全部消す。** `docs/adr/README.md` の「書き換えない」に正面から反する。0017 は「UI を gpui-kit から Tauri へ移す」という決定そのものなので、そこから gpui を消すと決定が読めなくなる。何から移ったかが消えれば、次に「なぜ Tauri なのか」を問われたときに答える材料が無い
- **コメントを直さずに放置する。** 45 箇所は放っておくと守られる。次に触る人は、確かめられない一致を保とうとして、直したほうがよい動きをそのままにする。実際 `web/src/board/keyboard.ts` は「**手触りが変わらないことがこの移行の条件**なので、ここで『もっと素直な動き』を発明しません」と書いていた。移行が終わった今、この文は「動きを直すな」とだけ読める
- **一致の記述を「歴史」として残し、日付を添える。** [0025](0025-the-tauri-migration-landed.md) が移行の設計文書に対して同じ案を退けたのと同じ理由で採らない。残せば読まれ、読まれれば規則として扱われる
- **`gpui` を CI で禁止語にする。** 掃除としては効くが、ADR に例外を切ることになり、そこに新しい ADR を足すたびに例外の穴を意識させる。禁じたいのは語ではなく「開けない参照を根拠にすること」で、それは機械では見分けられない

## 結果

- ソースを読む人が、コメントの根拠をその場で辿れるようになった。挙がっているのは、いま開けるコードか `docs/DESIGN.md` か ADR のいずれかになった
- 「なぜ Tauri なのか」「何から移ったのか」は [0017](0017-moving-the-ui-to-tauri.md) と [0025](0025-the-tauri-migration-landed.md) を開けば読める。**ただし、コードから ADR へ導く行は減った。** 移行の経緯が要る場面は今後ほとんど無いという読みで受け入れる
- 規則が 1 つ増えた。次に何かを置き換えたときは、置き換えたコードを消す作業に「参照を書き直す」が付いてくる
