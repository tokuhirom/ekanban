# 0009. `cmd-ctrl-*` に頼る操作には、macOS 以外の割り当てを別に持つ

- 日付: 2026-09-05
- 状態: 有効
- 関連: #53

## 状況

gpui の `cmd-` は platform 修飾キーで、macOS では Cmd、Linux と Windows では Super（Windows キー）になる。

[`docs/DESIGN.md`](../DESIGN.md) は「アプリ独自のショートカットは `secondary-` で定義する」としつつ、`cmd-ctrl-*` だけを例外にしていた。`secondary-ctrl-*` にすると非 macOS で `Ctrl` が重なり、`secondary-s`（保存）や `secondary-f`（検索）と衝突するためで、この理由自体は正しい。

結果として、フルスクリーン（`cmd-ctrl-f`）とボード一覧（`cmd-ctrl-s`）は Linux で `Super+Ctrl+*` になっていた。Super はデスクトップ環境が先に取るので、事実上どちらも押せない。終了（`cmd-q`）も同じく `Super+Q` で、`≡` メニューにも「終了」は置いていないため、Linux では「終了」という操作に届く手段が無かった。

## 決定

割り当てを、どの OS でも同じものと、OS ごとのものに分ける。

- 共通（`shared_key_bindings`）: `secondary-` で定義するアプリ独自の割り当て
- macOS（`platform_key_bindings`）: `cmd-ctrl-f` / `cmd-ctrl-s` と、システムメニューの `cmd-q` `cmd-h` `cmd-alt-h` `cmd-m`
- macOS 以外（同名の関数を `cfg` で差し替え）: `F11` フルスクリーン、`Ctrl+B` ボード一覧、`Ctrl+Q` 終了

macOS 以外では platform 修飾キーを 1 つも使わない。単体テストがそれを見ている。

## 理由

**`cmd-` の例外は macOS のためのものだった。** ほかの OS へそのまま持ち込むのは、例外を認めた理由の外側にある。持ち込んだ結果が「押せない割り当て」なら、それは割り当てが無いのと同じで、無いよりたちが悪い（マニュアルには載っている）。

**割り当てはその OS の慣習に合わせる。** `F11` は X11 と Windows のフルスクリーン、`Ctrl+Q` は終了として広く使われている。macOS の組み合わせを機械的に読み替えるより、その OS の人が最初に試す組み合わせのほうが届く。

**`Ctrl+B` は空いていた。** 脇の一覧を開け閉めする割り当てとしてもよくある形で、`secondary-shift-b`（ボードを追加）とも重ならない。

**macOS 側は 1 つも動かしていない。** 受け入れ条件がそう求めている。テストで固定した。

## 採らなかった案

- **`≡` メニューに「終了」を置く。** `docs/DESIGN.md` は `≡` メニューを「メニューバーが無い環境で同じ項目をたどれるようにするもの」としているが、ウィンドウと OS 側の操作（閉じる・終了・隠す）は意図的に外してある。終了に届かない理由はメニューではなく割り当てのほうにあったので、割り当てで直す。
- **`secondary-ctrl-*` を非 macOS でだけ使う。** `Ctrl` が重なって `Ctrl+F` / `Ctrl+S` と区別が付かない。例外を作った元の理由がそのまま残る。
- **全 OS で `F11` と `Ctrl+Q` にそろえる。** macOS で `Ctrl+Q` は終了ではないし、`F11` は既定で Mission Control に取られている。そろえること自体には値打ちがない。
- **すべての `cmd-*` を非 macOS でも登録したままにする。** 押せない割り当てが残る。テストで「Super を使わない」と言い切れなくなり、次に足す人が同じ間違いをする。

## 結果

Linux と Windows で、フルスクリーン・ボード一覧・終了に届くようになった。

引き受けたのは、同じ操作の割り当てが OS ごとに違うこと。マニュアルのショートカット表は元から macOS 列とその他の列に分かれているので、書く場所はある。

`cfg` で分けた 2 つの `platform_key_bindings` は、片方だけを直すと気づかないままになりうる。「終了・フルスクリーン・ボード一覧はどの OS でも割り当てを持つ」という単体テストを両方の側で回している。
