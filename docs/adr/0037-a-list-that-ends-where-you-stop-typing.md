# 0037. 箇条書きは打ち止めたところで終わる

- 日付: 2026-09-07
- 状態: 有効
- 関連: [0033](0033-a-markdown-editor-for-the-description.md)（広げる）

## 状況

説明を Markdown のエディタにした（[ADR 0033](0033-a-markdown-editor-for-the-description.md)）
あとで、使ってみて 2 つ出た。

- **箇条書きが終われない。** `- foo` と打って `Enter`、`bar` と打って `Enter`
  ——ここまでは自然だが、何も打たずにもう一度 `Enter` を押しても、次の項目が
  出続ける。段落に戻る道が無い
- **チェック項目が書けない。** `- [ ] 買い物` と打つと、`- ` が先に効いて
  箇条書きの項目になり、`[ ]` はただの文字として残る

どちらも Lexical の作りから来ている。1 つめは、箇条書きの振る舞い（`registerList`）
を持ち込んでいなかったため——節を作るのは Markdown の変換の仕事で、`Enter` を
どう読むかはプラグインの仕事だった。2 つめは 2 段構えで、`@lexical/markdown` の
既定の変換一覧に `- [ ]` が入っておらず、かつ記法を見るのが**段落の先頭だけ**
だったため（`- ` を打った時点で、そこはもう段落ではない）。

## 決定

**打ちながら整う範囲に、箇条書きの終わりとチェック項目を足す。**

- `ListPlugin` を入れる。何も打っていない項目で `Enter` を押すと箇条書きが終わり、
  行頭の `Backspace` は項目をほどく。**`Enter` を自分で捕まえない**
- 変換の一覧を `[CHECK_LIST, ...TRANSFORMERS]` にする。先頭に置くのは、
  `- [ ] 買い物` を「箇条書き」と読まれる前に「チェック項目」と読ませるため
- **項目の中で `[ ] ` と打たれたときだけ、自分で見る**（`Description.tsx` の
  `CheckItem`）。`@lexical/markdown` は届かない場所なので、そこは `TextNode` の
  変換で拾い、`@lexical/list` の `$insertList("check")` に渡す
- 印を押して付け外しできる（`CheckListPlugin`）。保存される形は `- [ ] ` と `- [x] `
- **カードのチェックリスト欄（`Card.checklist`）はそのまま。** カード表面に
  進み具合を出すのは、これまでどおりそちらだけ

## 理由

**`Enter` は「次の項目」と「終わり」を兼ねる。** 続けるかどうかを知っているのは
打ち手で、それを言う手立ては「何も打たずにもう一度押す」しかない。箇条書きの
ある編集器はどれもそうしていて、ここだけ違うと手が止まる。

**判断を 2 か所に置かない。** `Enter` を自分で捕まえて段落に戻すこともできるが、
入れ子の項目、番号の振り直し、`Backspace` でほどくところまで同じ判断で動く必要が
ある。`registerList` が持っているものを使うほうが、食い違わない。

**チェック項目は、書ける場所を増やすだけ。** `Card.checklist` は「終わったか」を
数えて**カード表面に出す**ためのもので、並べ替えも 1 項目ずつの確定もある。説明の
中のものは文章の一部で、数えない。**どちらか一方に寄せない**のは、寄せた側が
もう一方の役目まで負うから——説明の中の印を数え始めると、カードの高さが中身で
変わる（`docs/DESIGN.md`）。

**混ぜられる形に見せかけない。** Lexical では「印が付くかどうか」は箇条書き全体の
性質で、1 つの箇条書きに印のある項目と無い項目を混ぜられない。項目の 1 つを
チェック項目にすると、その箇条書き全体がそうなる。書いたものと保存される Markdown
が食い違わないほうを採った。

## 採らなかった案

- **`Enter` を自前で読む。** 上のとおり、判断が 2 か所になる。
- **エディタを別のライブラリに替える。** 求めていた振る舞いは、どちらも今の
  ライブラリで出せた（前者はプラグイン 1 つ、後者は変換の足しと 20 行）。
  替える理由が無い。
- **`Card.checklist` を説明の中のチェック項目に寄せる。** カード表面の進み具合と
  並べ替えを失う。移行も要る。
- **説明の中の印を数えてカード表面に出す。** カードの高さが中身で変わる
  （`docs/DESIGN.md`「カード表面の高さは…変えない」）。

## 結果

`- foo` `- bar` と打ったあとの `Enter` で箇条書きが終わり、`- [ ] ` で書いた項目は
押して付け外しできるようになった。保存される形は Markdown の文字列のままで、
書き出しもデータベースも変わっていない。
