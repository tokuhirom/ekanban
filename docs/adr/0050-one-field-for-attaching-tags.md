# 0050. タグを付ける欄は 1 つの部品に寄せる

- 日付: 2026-09-10
- 状態: 有効
- 関連: #115 #198（[0027](0027-creating-tags-while-editing-a-card.md)、[0049](0049-recurring-cards-are-defined-apart-from-the-board.md)）

## 状況

タグを付ける場所が 2 つあり、**同じことをするのに見た目も操作も違っていた**。

- カードの編集パネル（[0027](0027-creating-tags-while-editing-a-card.md)）は、付いて
  いるタグをチップで出し、打ち込み欄に名前を打って `Enter` で付ける。無い名前を
  打てばその場で作る。
- 繰り返しの定義パネル（[0049](0049-recurring-cards-are-defined-apart-from-the-board.md)）は、
  **ボードのタグを全部押しボタンで並べ**、押して付け外しする。打ち込む欄が無いので
  新しいタグは作れず、タグ整理パネルへ往復するほかなかった。

後者は [0027](0027-creating-tags-while-editing-a-card.md) が前者から外した形そのもの
である。付ける先がカードか定義かの違いしかないのに、**打ち方を思い出し直す**ことに
なっていた。

## 決定

タグを付ける欄を `web/src/panel/TagsInput.tsx` の 1 つの部品にし、カードの編集
パネルと繰り返しの定義パネルの**両方がそれを使う**。

繰り返しの定義パネルからも、打った名前のタグが無ければその場で作って付けられる。
そのときの**作るのと付けるのは 1 回の `run()` にまとめる**——定義パネルは触った
時点で確定する作りなので（[0049](0049-recurring-cards-are-defined-apart-from-the-board.md)）、
分けると「作っただけで付いていない」状態が置き場所に残る。

`docs/DESIGN.md`「タグを作れるのは、タグ整理パネルと、カード編集パネルのタグ欄の
2 か所」を、「タグを付ける欄は 1 つの部品に寄せる。作れる道はその欄とタグ整理
パネルの 2 つ」に書き換える。

## 理由

[0027](0027-creating-tags-while-editing-a-card.md) が「付ける」と「編む」を分けた
線は、付ける先がカードでも繰り返しの定義でも同じところに引ける。**付けるものが
同じなら、打ち方も同じにする**。

ボードのタグを全部並べる形は、[0027](0027-creating-tags-while-editing-a-card.md) と
#169 が既に一度やめている——タグが増えるほど、いま書いているもの 1 つの話をして
いる場所をボード全体のタグの一覧が埋める。繰り返しのパネルは定義の数だけその
一覧が縦に並ぶので、同じ不都合がタグ数×定義数で効く。

部品が 1 つになれば、`Enter` での確定、IME の変換中の扱い（[0029](0029-detecting-ime-composition.md)）、
空の欄での `Backspace`、候補の出し方が、片方だけ直る形にならない。

## 採らなかった案

- **繰り返しのパネルの押しボタンをそのままにして、打ち込み欄だけ足す。** 同じ
  ことをする道が 1 つの欄の中に 2 つ並ぶ。どちらで付けても結果は同じなのに、
  画面はカードの編集パネルと違うままになる。
- **カードのタグ欄のほうを押しボタンに揃える。** タグの数だけ画面が埋まる形へ
  戻ることになる。[0027](0027-creating-tags-while-editing-a-card.md) と #169 が
  その理由でやめた形なので、覆すなら別の理由が要る。
- **`tags.ts` に部品を同居させる。** あそこはタグの上の純粋な操作（突き合わせ、
  候補、色）を置く場所で、React を持ち込まない。ファイルを分ける。

## 結果

タグを付ける打ち方が画面をまたいで 1 つになり、繰り返しの定義にもその場で新しい
タグを付けられるようになった。

引き受けた不都合は、繰り返しのパネルで**ボードのタグを一覧できなくなった**ことで
ある。付けたいタグの名前をうろ覚えのときは、打ちはじめれば候補が出る。どんなタグが
あるかを一覧するのは、これまでどおりタグ整理パネルの仕事にする。
